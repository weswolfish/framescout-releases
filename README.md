## Compatibility

- Windows 10 or Windows 11, x64
- Per-user installation; administrator access is not required
- Self-contained: Python, Node.js, FFmpeg, and a browser are not required
- Local and privacy-first: video processing and reference boards remain on the computer

## Beta notice

This beta is unsigned. Windows SmartScreen may show an **unrecognised app** warning. Verify the download against `SHA256SUMS.txt` before choosing **More info → Run anyway**.

Mobile, browser, macOS, Linux, direct Instagram posting, and automatic updates are not included in this beta.

Report beta problems through this repository’s [Issues](https://github.com/weswolfish/framescout-releases/issues). Include the FrameScout version, Windows version, the operation that failed, and any non-sensitive error text. Do not upload private videos or reference images.
